# slong8254.github.io
개인 웹페이지

[포트폴리오 보기](https://slong8254.github.io/)

GitHub Pages는 `main` 브랜치의 루트에서 `index.html`과 `styles.css`를 제공합니다. 별도의 빌드, 서버, 데이터베이스, API 호출이 필요하지 않습니다. `.nojekyll`은 Jekyll 처리를 건너뜁니다.

자기소개, 프로젝트, 학력·경력·자격증을 업데이트하려면 `index.html`의 해당 섹션을 수정합니다. 브라우저에서 `index.html`을 열어 변경을 확인할 수 있습니다.
